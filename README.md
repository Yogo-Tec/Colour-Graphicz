# 11. Dynamic Data Structure

To make the website easier to maintain, we can keep changing content in JSON files.

For example:

```text
data/
├── services.json
├── portfolio.json
├── gallery.json
├── testimonials.json
└── faq.json
```

Then JavaScript can dynamically load the content.

For example:

```text
portfolio.json
        ↓
portfolio.js
        ↓
Portfolio HTML
        ↓
Filter / Search / Modal
```

This means you don't have to manually rewrite the HTML every time you add a portfolio project.
